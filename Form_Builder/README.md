# Form Builder

## Problem Statement
Build a form builder with a side panel to configure and add different form inputs (text, number, email, checkbox, select, textarea). Added elements appear on the form in real time. Clicking submit logs all form values as an object.

## Features
- Side panel to configure field type, label, placeholder, options (for select), and required flag
- Real-time preview of the form as fields are added
- Remove fields from the form
- Submit button console logs all values as `{ label: value }` object

## Run
```bash
npm install
npm run dev
```
